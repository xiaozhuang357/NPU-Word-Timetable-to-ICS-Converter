# 课表 ICS 生成器 📅

一个简洁强大的 Web 工具，将 Word 格式的课程表批量转换为 iOS/macOS 日历兼容的 .ics 文件，支持直接导入 iPhone、iPad、Mac 日历和 Google Calendar。

## 功能特性

✨ **智能识别**
- 自动解析标准教务系统导出的 Word 课程表
- 支持合并单元格（rowspan/colspan）
- 支持同一时段多课程识别（不同周次不同课程自动拆分）
- 内置 13 种教室关键词识别，支持自定义地点

📋 **灵活配置**
- 自定义学期起始日期、学期名称、总周数
- 可视化编辑节次时间表
- 支持手动添加/编辑课程
- 实时课程表预览

📱 **标准兼容**
- 生成标准 iCalendar 格式 (.ics)
- 支持 iOS/macOS 日历、Outlook、Google Calendar 等
- 每堂课单独事件，自动生成多周重复日程
- 课程名 + 教室在日历标题中显示

🔒 **隐私优先**
- 完全本地处理，无服务器上传
- 开放源代码，可自由审查

## 使用方法

### 方式一：在线使用
访问 [项目 GitHub Pages](https://github.com/your-username/ics/pages)（部署后可用）

### 方式二：本地使用
1. 克隆或下载项目
2. 用浏览器直接打开 `index.html`
3. 按步骤上传课表、配置参数、预览编辑、生成下载

### 步骤说明

**1️⃣ 上传课表**
- 支持 .docx 格式的 Word 文件
- 拖拽或点击选择文件
- 点击「识别课程」开始解析

**2️⃣ 配置学期**
- 设置第一周周一日期
- 设置起始周次（通常为 1）
- 设置总周数（通常为 16-20）
- 可选：输入学期名称、自定义地点关键词
- 可选：编辑节次时间表

**3️⃣ 预览编辑**
- 查看课程总数、科目数、总课次
- 可视化课程表，支持点击编辑或删除
- 支持手动添加新课程
- 可通过「查看表格结构」调试识别问题

**4️⃣ 生成下载**
- 点击「生成并下载 ICS」，获得 .ics 文件
- 在 iOS/Mac 日历中双击或用日历 App 打开导入

## Word 课表格式要求

本工具支持以下常见教务系统导出的课表格式：

### 基本结构
- **表格式课表**：行为节次（第 1-13 节），列为星期一至星期日
- 每单元格包含：课程名、教师、教室、周次等信息
- **支持合并单元格**（rowspan/colspan）

### 单元格内容格式（自动识别下列任意格式）

#### 标准格式
```
课程名 编号
(周次) (节次) 教室 教师
```

#### 同一时段多课程（不同周次不同课程）
```
复变函数与积分变换 02
(1~8周) (1-2节) 教西D-104 朱项项

软件理论与工业应用前沿技术 01
(11周) (1-2节) 教西A-203 冯喜康
(12周) (1-2节) 教西A-203 王君波
```

#### 周次表达式支持
- 单个周：`(11周)` `第11周` `[11]`
- 周次范围：`(1~8周)` `(1-8周)` `第1-8周`
- 单/双周：`(1~8(单)周)` `(1~8(双)周)`
- 逗号分隔：`(1,3,5周)` `(2和4周)`

#### 教室识别（自动匹配）
内置支持：
- 教西/教东/教南/教北 系列：`教西D-104`、`教东B2-506`
- 楼号格式：`1号楼 A-301`、`响应楼 201`
- 实验系列：`实验楼 203`、`实验大楼 1楼`
- 体育场馆：`体育馆`、`游泳池`、`操场`
- 其他：`启翔楼`、`翱翔体育馆` 等

**若教室未被识别**，在步骤2配置中的「自定义上课地点」添加关键词

## 常见问题

### Q：为什么识别失败或识别错误？
A：
1. 检查课表格式是否规范（行为节次、列为星期）
2. 使用「查看表格结构」功能调试，查看原始表格被如何解析
3. 手动调整或使用「手动添加」逐条录入
4. 若教室未识别，在「自定义地点」中添加关键词

### Q：如何导入到 iPhone 日历？
A：生成的 .ics 文件可通过以下方式导入：
- **直接打开**：用邮件发送 .ics 文件到 iPhone，点击打开即可
- **iCloud 同步**：在 Mac 上导入，通过 iCloud 同步到 iPhone
- **Calendar App 导入**：在 iOS 日历 App 中，通过"导入"功能选择文件
- **第三方应用**：许多日历应用（Google Calendar、Outlook 等）均支持导入

### Q：课程显示在日历里的格式是什么？
A：
- **标题**：`课程名 教室`（如"计算机网络 教西D-101"）
- **时间**：按配置的节次时间表显示
- **描述**：包含教师、周次、节次信息
- **重复**：自动为课程的所有周次生成事件

### Q：数据安全性如何？
A：
- ✅ 完全在浏览器本地处理
- ✅ 无服务器通信，无数据上传
- ✅ 源代码开放，可自由审查

## 核心算法

### 表格解析
1. **Grid Builder**：将 HTML 表格转换为二维网格，处理 rowspan/colspan
2. **Day Detection**：自动检测星期标题行和列映射
3. **Period Detection**：自动检测节次列和行-节次映射
4. **Cell Parser**：逐单元格解析课程信息，自动拆分多课程

### 课程识别
- **多课程拆分**：按双换行分块，按课程名分组，按条目行按期拆开
- **周次识别**：支持 10+ 种周次表达格式，自动标准化
- **教室识别**：正则匹配 + 用户自定义关键词
- **教师提取**：捕获教室后的人名或行末人名
