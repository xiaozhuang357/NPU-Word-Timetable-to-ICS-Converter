# 翱翔课表 · NPU Calendar

面向西北工业大学长安校区的 Word 课表识别与 ICS 日历生成工具。文件在浏览器本地处理，不上传课表，也不保存个人信息。

## 这版解决了什么

- 针对教务系统课表的合并单元格、星期列和第 1–13 节结构进行识别。
- 将 `10-17大学英语核心能力` 自动拆成“大学英语核心能力”和第 10–17 周。
- 同一课程在不同周次更换教师、教室或节次时，分别保留排课段，不再用最后一条覆盖前面的信息。
- 支持连续周、离散周、单周、双周和多种中英文标点写法。
- 导出前检查缺失字段、可疑课程名、重复课次和时间冲突。
- 每次实际上课生成独立 `VEVENT`，适配 Apple 日历、Google Calendar、Outlook 等应用。
- 使用 `Asia/Shanghai` 时区，标题、地点和描述字段均按 RFC 5545 转义与折行。

## 长安校区默认作息

内置时间来自西北工业大学公开的[两校区作息时间对照表](https://hangtian.nwpu.edu.cn/info/1945/15896.htm)。其中第 13 节为 `20:40–21:25`。

| --- | --- | --- | --- |
| 1 | 08:30–09:15 | 8 | 14:55–15:40 |
| 2 | 09:25–10:10 | 9 | 16:00–16:45 |
| 3 | 10:30–11:15 | 10 | 16:55–17:40 |
| 4 | 11:25–12:10 | 11 | 19:00–19:45 |
| 5 | 12:20–13:05 | 12 | 19:55–20:40 |
| 6 | 13:05–13:50 | 13 | 20:40–21:25 |
| 7 | 14:00–14:45 |  |  |

## 本地运行

```bash
npm install
npm run dev
```

然后打开终端中显示的本地地址。由于页面使用 ES Modules，不建议直接双击 `index.html`。

## 测试

```bash
npm test
```

测试覆盖周次黏连、单双周、换教师、合并单元格、时间冲突、ICS 日期和第 13 节结束时间。

## 文件结构

- `index.html`：页面结构与可访问性标记。
- `styles.css`：iOS 风格的响应式界面、深色模式和动效。
- `app.js`：文件导入、结果编辑、预览与下载交互。
- `schedule-core.js`：可独立测试的课表解析、质量检查和 ICS 生成核心。
- `public/vendor/mammoth.browser.min.js`：本地 Word 转换组件，避免运行时依赖第三方 CDN。
- `tests/schedule-core.test.js`：解析与导出回归测试。

## 隐私说明

课表解析完全发生在当前浏览器页面内。应用没有上传接口、账号系统或分析脚本；关闭页面后，课表内容不会由本工具保留。
